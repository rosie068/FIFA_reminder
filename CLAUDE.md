# FIFA 2026 World Cup Reminder + Predictor

macOS desktop app that pops a rolling-soccer-ball animation 1 hour before kickoff for the user's followed teams, and shows win/draw/lose probabilities for every group-stage match.

## Layout

```
FIFA_2026/
├── FIFA.md                      # Research dataset (source of truth): all 72 group matches,
│                                # kickoffs in PDT, venues, de-vigged win/draw/loss probabilities,
│                                # bookmaker odds, team form/injuries. Snapshot dated 2026-06-12.
└── WorldCupReminder/
    ├── Sources/main.swift       # Entire app — single file (models, store, views, overlay, app delegate)
    ├── Resources/
    │   ├── matches.json         # JSON block extracted verbatim from FIFA.md (72 matches, 48 teams)
    │   ├── goal.png             # Goal clipart used in the reminder animation (user-provided)
    │   └── Info.plist
    ├── make_icon.swift          # Renders ⚽ emoji → iconset PNGs (run by build.sh)
    ├── build.sh                 # Build script — see below
    └── build/World Cup Reminder.app   # Output (gitignored-style artifact; rebuild anytime)
```

## Build & run

```sh
cd WorldCupReminder && ./build.sh
open "build/World Cup Reminder.app"
```

No Xcode project, no SPM — `build.sh` compiles `Sources/main.swift` with `swiftc -O -parse-as-library`, assembles the .app bundle, generates the ⚽ icns, and **ad-hoc codesigns** (`codesign -s -`). Signing is required or `UNUserNotificationCenter` crashes. Requires macOS 13+, tested on macOS 26.5 / Swift 6.3.

Kill/relaunch during iteration: `pkill -f WorldCupReminder`.

## Architecture (all in main.swift)

- **Models** — `Match`, `TeamInfo`, `Prediction` decoded from bundled `matches.json`. `bookmaker_odds` is deliberately NOT decoded (mixed Int/String in JSON; probabilities suffice).
- **`Store`** (singleton, ObservableObject) — loads dataset; `selectedTeams: Set<String>` persisted to UserDefaults key `selectedTeams` (bundle id `ai.trifetch.worldcupreminder`). Changing selection reschedules everything.
- **Reminders, two layers**:
  1. *Primary*: 30s `Timer` in AppDelegate calls `Store.checkDueReminders()`. When now ∈ [kickoff−1h, kickoff) for a followed team's match → fires the `OverlayController` animation and cancels that match's system banner. Fired IDs persisted under UserDefaults key `firedReminders` (no duplicates across relaunches).
  2. *Fallback*: `UNUserNotificationCenter` calendar-trigger banners scheduled at kickoff−1h for all followed matches — only ever seen if the app isn't running at fire time.
- **`OverlayController` / `GoalOverlayView`** — borderless transparent NSWindow, full width × 340pt strip at bottom of `NSScreen.main`, level `.statusBar`. ⚽ rolls from right edge into `goal.png` at bottom center (2.8s, spins), then neon-green card (Color(0.30, 0.94, 0.10), black "Marker Felt" text 19–26pt, black border) pops with match + probabilities. Click anywhere dismisses; auto-dismiss ~18s. "Preview Goal" button in main window triggers a demo.
- **Probability orientation** — `Store.predictionLine(for:)` flips home/away probs so text reads "<your team>: win X% · draw Y% · lose Z%" when exactly one side is followed.
- **UI** — regular window (WindowGroup) + ⚽ menu bar status item with popover (same ContentView). Dock icon intentionally enabled (`LSUIElement` was removed: user's menu bar is full and macOS hid the status item). Two tabs: team picker (grouped by group, search, FIFA rank) and match list (upcoming/played, probability bars).

## Updating data

`FIFA.md` is regenerated by a research agent. To refresh the app:

1. Re-extract: `awk '/^```json$/{f=1;next}/^```$/{f=0}f' FIFA.md > WorldCupReminder/Resources/matches.json`
2. Rebuild + relaunch.

Per FIFA.md's own guidance: update `result`/`status` after each match, and odds drift — refresh within 24h of kickoff for accuracy. Currently static snapshot from 2026-06-12; no live odds API (was discussed, not built).

## Known constraints / decisions

- Animation shows on `NSScreen.main` only (user has MacBook + ultrawide; multi-screen targeting was offered, not requested).
- All kickoff times in dataset are already PDT (`America/Los_Angeles`); parsing assumes that timezone.
- User declined nothing notable; pending offers: copy app to /Applications + Login Items for auto-start.
- Group stage only (72 matches, through June 27). Knockout-round data doesn't exist yet — needs new research pass + dataset extension after groups finish.
